# Контроль сохранения приватного кандидата 0.6.0, 10.11.2026

## Объём принятого промежуточного этапа

По решениям владельца подготовлены прямой Google Sheets read-only адаптер, широкая карта
отчёта, клиентский вход через Google без service account по умолчанию и обновление перед
отчётами. Старый финансовый контракт и искусственное демо сохранены. Это промежуточный
технический этап, не DoD публичного выпуска или независимого внешнего теста.

Потребители: локальный stdio-клиент, отдельно размещённый HTTP-клиент с собственным
OAuth, генераторы plugin packages, агент-настройщик. Для прочих адаптеров автообновление
не включено. Google Desktop flow не реализует серверный Web callback.

## Проверка

Полный unittest suite: 60 тестов, 53 успешны, 7 PostgreSQL пропущены без PG-runtime.
Положительный контроль: обновлённое синтетическое значение приходит в новый tool answer;
wide-карта и пропуски проверены. Отрицательный: ошибки чтения/структуры/границы/клиента,
неверный state/scope, отказ входа/отзыва не маскируются успехом и не выдают старый отчёт.
Прежнее поведение: существующие stdio, CSV/XLSX, HTTP security и plugin tests успешны.

Отдельно в Windows владельца: настоящий Google login, защищённый keyring, принудительный
refresh Google grant, повторный процесс, get_passport/list_months/refresh_source/get_cashflow.
Данные получены, оригинал не менялся. Акт и клиентские данные только в приватном журнале
владельца; в этот исходный репозиторий и тестовые fixtures не включены.

## Ревью

**approve для сохранения промежуточного read-only кандидата.** Оркестратор просмотрел
diff, границы доступа, безопасные сообщения, атомарную замену снимка, отсутствие записи
Google, исключение runtime credentials из архива и сохранение старого контракта. Проверки
и Windows live-приёмка подтверждают этот объём; независимый аудит безопасности не заявлен.

## Открыто и статус

Внешний тест другого пользователя, проверка изменённой ячейки в отдельной книге,
пользовательский UI/дашборд, PG-runtime, Google Production verification, распространение
зарегистрированной Desktop app-конфигурации и полноценный remote Google Web callback
остаются открытыми. Реальные OAuth настройки/ключи/гранты в исходники не добавлять.
Публичный выпуск, каталог, PyPI и выкат в этой операции не выполняются.
