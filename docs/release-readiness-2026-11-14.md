## Границы упаковки

Wheel устанавливает модуль и встроенные инструкции. Sdist содержит модуль
и тесты, но не включает верхнеуровневые docs, examples, scripts, AGENTS.md
и preflight.py. Поэтому для самостоятельной работы по README и воспроизведения
всех тестов нужен полный GitHub-архив исходников; sdist не следует выдавать
за такой комплект. До отдельного выпуска PyPI состав sdist стоит исправить.

Локальный Windows-комплект с приложением автора — отдельный артефакт;
его нельзя автоматически считать публичным релизом исходников.
