# TASK-578 — подключение существующих Google-отчётов без переделки книги

Статус: implemented; внешний UI не принят. Основание: запрос Татьяны 11.11.2026 и внешний отказ 0.7.0rc1.
Срок: до следующего внешнего теста. Кандидат: 0.7.0rc2.

## Проблема и результат
0.7.0rc1 отклоняет готовый ДДС с колонкой Итого и остатки с двумя колонками названия
и числовыми датами Google. Агент предлагает другую тестовую книгу.
Новый комплект читает существующую согласованную книгу без записи/копирования,
обнаруживает ДДС и остатки, объясняет охват, сохраняет исходные суммы и старые подключения.
Ссылка/данные книги остаются только в приватной проверке, не в исходниках/ZIP.

## Потребители ниже по потоку
google_connect → сохранённая wide-карта → GoogleSheetsAdapter.refresh → FinanceService →
семь MCP-инструментов → local_setup/Codex → анализ агента.
Изменение карты обязано сохранять совместимость старых профилей, проверять идентичность
листа/заголовков/названий строк и блокировать устаревший ответ при ошибке обновления.
Композитные подписи остатков не суммируются; Итого по разным месяцам не подменяет месяц.
Журнал/регулярные/план не являются автоматически готовыми фактическими отчётами.

## Реализация и границы
- Разрешить явно именованные служебные/итоговые колонки без включения в месячный отчёт;
  неизвестные дополнительные денежные колонки не отбрасывать молча.
- Распознать месячные числовые даты при заголовках Счёт + Показатель, сохранить обе
  исходные подписи каждой строки и проверять их при refresh.
- Сохранить разделы ДДС/пропуски с честным complete=false; примечания остатков
  отделить от денежных строк и зафиксировать их в карте, чтобы не потерять изменения.
- Проценты/количества не выдавать как валюту; название процентов по займам само по себе
  не означает процентную единицу денежной строки.
- Не принимать строки журнала с датой/месяцем за заголовки месячного отчёта.
- При неоднозначной структуре сообщать точную границу и передавать разбор карты агенту,
  не требовать другую книгу, копию или переделку отчёта.
- Обновить AGENTS, docs, packaged resources и Начать.txt в сборщике, версию и changelog.
- Новый архив с зарегистрированным Desktop public client; без grants, keyring,
  клиентских снимков, ID книги, venv. Старый внешний комплект сохраняется.

## Приёмка
- Регрессия исходных адаптеров/stdio/local_setup; синтетические сценарии реальной
  структуры ДДС и остатков, 0/missing, смешанные единицы, служебные колонки/заголовки,
  изменение карты, ошибка refresh, сохранение старой конфигурации Codex.
- Приватная построчная проверка всех денежных ячеек двух фактических отчётов
  по захваченным ответам коннектора, без изменения книги. Это не банковская сверка.
- Независимое ревью с чистым контекстом и устранение существенных находок.
- Проверка нового ZIP и Windows установки/stdio в отдельном окружении при наличии
  разрешения владельца. UI тестировщика остаётся внешней проверкой.
- Коммит/пуш исходников, запись точных результатов и SHA256 выданного ZIP в журналы.
