# История изменений

## 0.6.0 — приватный кандидат, внешняя приёмка продолжается

- Google Sheets: чтение согласованной книги и явная карта широкого отчёта, сохранение пропусков.
- Вход Google OAuth Desktop без сервисного аккаунта клиента: PKCE/state, readonly scope,
  OS keyring, обновление и отзыв разрешения. Автор регистрирует приложение отдельно.
- Автоматическое перечитывание Google перед финансовым отчётом; сбой не выдаёт старые суммы как свежие.
- После установки агент предлагает анализ или дашборд, учитывая фактическую полноту данных.
- Windows-вход владельца, OS keyring, Google refresh и реальные stdio вызовы проверены.
  Внешний UI, изменённая ячейка, Google Production verification и web callback ещё не приняты.
- Настройки зарегистрированного Google-приложения и пользовательские токены не входят в репозиторий.

## 0.4.0 — кандидат, не опубликован в публичном каталоге

- Общий финансовый контракт для stdio и защищённого Streamable HTTP.
- OAuth resource server: RS256/JWKS, issuer/audience/expiry/scope и allowlist sub.
- Генерация индивидуальных local/remote plugin packages с onboarding skill.
- Выбор приложения в начале диалога, самостоятельный сервер владельца без сервера автора.
- Docker/Caddy-примеры. Реальный OAuth-провайдер, хостинг и ChatGPT UI требуют отдельной проверки.

## Кандидат первого публичного выпуска — не опубликован

- Сценарий отказа сохранения MCP-конфигурации: точная диагностика/минимальные права,
  одно действие владельца и отдельная проверка реальных MCP-вызовов после регистрации.

- По промежуточной внешней обратной связи: поэтапное сопровождение владельца без
  технической анкеты; объяснение готовности периода и частичного ОПиУ до валовой прибыли.

- Бренд «Финагент» и ссылки на сервис в README, метаданных и демопаспорте.
- Лицензия MIT; правообладатель — Самойлова Татьяна.
- Добавлены порядок участия, контакты безопасности и автоматические проверки GitHub.
- Расчётные данные, адаптеры и интерфейс версии 0.3.0 сохранены.

## 0.3.0 — исходный комплект для независимого тестирования

Локальный stdio; CSV/XLSX/PostgreSQL-адаптеры; диагностика среды;
неизвестные даты состояния; постоянные коды статей; шаблон акта сверки.
Удалённый HTTP/OAuth и автоматическое обновление не включены.
