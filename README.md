# Финагент MCP — финансовые отчёты для AI-ассистента

[**Посмотреть сервис «Финагент» →**](https://finuchetai.ru/?utm_source=github&utm_medium=opensource&utm_campaign=finance_mcp)

Автономный финансовый MCP от проекта «Финагент»: подключайте подготовленные отчёты
к своему локальному AI-ассистенту и задавайте вопросы о прибыли, движении денег и остатках.
Для самостоятельного запуска используйте инструкции ниже. Если нужна помощь с подключением
данных и управленческим учётом, [оставьте заявку на сайте сервиса](https://finuchetai.ru/?utm_source=github&utm_medium=opensource&utm_campaign=finance_mcp#lead-form).

Репозиторий: `finagent-mcp`. Имя устанавливаемого Python-пакета `open-finance-mcp`;
команды запуска `finance_mcp.server` сохранены для совместимости с комплектом 0.3.0.

Версия 0.4.0: демо, адаптеры CSV/XLSX/PostgreSQL, проверка среды и реестр кодов. Этот каталог целиком переносим: ему не нужны остальной
репозиторий, база, домен, ключи или сервисы автора. Источник — вымышленная мастерская
«Маяк», два закрытых месяца и один открытый. Даты фиксированы для воспроизводимости.

## Если вы устанавливаете MCP через ассистента

Передайте ему: «Прочитай AGENTS.md и docs/guided-setup.md. Сначала спроси, где я хочу
работать: браузер, настольный ChatGPT или другой клиент. Веди меня по одному шагу,
объясняй термины и выполняй техническую настройку сам. Не задавай все вопросы о данных
одной анкетой. Сначала посмотри разрешённый источник и объясни, что можно подключить».

[Поэтапная настройка простыми словами](docs/guided-setup.md). Неполный ОПиУ, например
только до валовой прибыли, поддерживается с явно указанными ограничениями; отсутствие
чистой прибыли не требует выдумывать её или дополнять исходник нулями.

## Быстрый запуск

Нужен Python 3.11+ с venv/pip и доступ к индексу Python-пакетов при первой установке.
Скопируйте **только этот каталог** в отдельное место. Внутри копии:

```sh
python3 preflight.py environment
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m finance_mcp.diagnostics stdio --timeout 15
.venv/bin/python -m unittest discover -s tests -p test_demo.py -v
.venv/bin/open-finance-mcp
```

Последняя команда ждёт сообщений MCP на stdin; пустой экран — нормально. Завершение:
Ctrl+C. Сервер запускается помощником как дочерний процесс; отдельный фоновой сервис
и открытый порт ему не нужны. На Windows используйте `.venv\Scripts\python.exe`.

## Подключение к локальному агенту

В настройках MCP клиента, поддерживающего stdio, укажите **абсолютный** путь к Python
созданной venv. Структура конфигурации зависит от клиента; типовой фрагмент:

```json
{
  "mcpServers": {
    "finance-demo": {
      "command": "/absolute/path/to/demo/.venv/bin/python",
      "args": ["-m", "finance_mcp.server"]
    }
  }
}
```

Рабочая папка клиента может быть любой: код установлен в venv, данных с относительными
путями нет. Проверка ниже использует настоящий subprocess из временной рабочей папки.
В 0.4.0 добавлен защищённый Streamable HTTP для удалённых клиентов и генератор
локального/удалённого плагина. [Выбор клиента и самостоятельное размещение](docs/connection-modes.md).
Для браузера потребуются сервер владельца, HTTPS и настроенный OAuth-провайдер;
публикация кода сама по себе их не создаёт.

Передайте агенту: «Прочитай AGENTS.md, установи этот пакет в отдельную venv, выполни
проверки и помоги добавить stdio MCP в мой локальный клиент. Покажи прибыль и остаток
денег за сентябрь 2026 и объясни, почему прибыль отличается от движения денег».

Ожидаемо: прибыль сентября **75000.00 RUB**, движение денег **80000.00 RUB**,
остаток на конец **155000.00 RUB**. Это учебные числа; сначала прочитайте паспорт.

## Интерфейс адаптера (контракт 1.1)

`finance_mcp.contract.FinanceAdapter` — Python Protocol без зависимости от MCP SDK:

- `passport() -> str`: подтверждённая методика и ограничения одного клиента;
- `periods() -> tuple[Period, ...]`: периоды и доступные отчёты;
- `report(kind, month) -> Report`: ОПиУ, ДДС или остатки;
- `notes(month) -> str`: примечания закрытого периода.

Собственный адаптер передаётся в `finance_mcp.server.create_server(adapter)`. Сервер
не знает SQL, таблиц и файлов источника. Без --config CLI запускает DemoAdapter;
подключение CSV/XLSX/PostgreSQL выбирается через `--config`. Контракт не является механизмом
авторизации: будущий адаптер обязан обеспечивать права на стороне источника.

`Report`: тип, период, валюта ISO-кодом, источник, as_of (подтверждённая дата состояния
с TZ или null), отдельные received_at / as_of_status / source_time_raw,
`complete` и непустой tuple строк. Строка: устойчивый `code`, название, разрез,
`Decimal` и статус `value`/`missing`/`not_applicable`. Последние два означают `None`,
в JSON — `null`, и отличаются от денежного нуля. Пропуск требует `complete=false`.
Уникальность строки — `(code, dimension)`. Итоги имеют собственные коды; правила
сложения описывает паспорт, инструмент не складывает строки и не конвертирует валюты.
Разные отчёты могут иметь разные валюты, это всегда явно в ответе каждого отчёта.

`FinanceService` проверяет запрос целиком до загрузки отчётов: 1–12 уникальных периодов,
закрытость и доступность отчёта; неверный запрос отклоняется, частичного успешного ответа нет.
Проверяется соответствие возвращённого отчёта запросу. Деньги сериализуются строками;
ответ — один текстовый JSON без дублирования в structuredContent.

## Проверки и границы готовности

Тесты сверяют все 24 строки демо, денежные тождества и разные смыслы нуля/пропуска,
подставляют второй адаптер через публичный интерфейс, проверяют отказ на открытый,
отсутствующий и испорченный период. Интеграция запускает установленный сервер по stdio,
делает initialize/list_tools и вызывает все шесть инструментов, включая отрицательные
сценарии и повторный запуск. Никаких подключений к реальным финансовым системам нет.

Перенос: скопируйте preflight.py, README.md, AGENTS.md, pyproject.toml, src/, tests/, docs/ и examples/.
Не переносите `.venv`, `build`, `*.egg-info`, кэши или настройки исходного проекта.
Удаление установки: остановите MCP в клиенте, уберите его конфигурацию, удалите копию
пакета и venv. Секретов и внешних ресурсов это демо не создаёт.

Для публичного выпуска выбрана лицензия MIT; текст — [LICENSE](LICENSE).
Правообладатель: Самойлова Татьяна. Этот кандидат готовится к первому публичному
выпуску; GitHub-репозиторий пока приватный. См. [порядок выпуска](docs/release-checklist.md).
SDK: [официальная документация stdio](https://py.sdk.modelcontextprotocol.io/run/).

## Источники клиента

Установите `pip install '.[files,postgres]'` внутри venv. Примеры вымышленного клиента
«Липа» — examples/lipa: 40 строк, 7 отчётов, две точки. Проверка CSV:
`python -m finance_mcp.server --config examples/lipa/csv.json --check`.
В аргументы MCP-клиента добавьте `--config` и абсолютный путь к JSON.
[Формат экспорта, Excel, PostgreSQL, права, обновление и полный прогон](docs/sources.md).

[Проверка среды, короткая stdio-проба, даты и постоянные коды](docs/readiness.md).
Примеры в examples/lipa: csv-registry.json для реестра и csv-dates.json для неизвестной
даты состояния. [Шаблон акта сверки](docs/acceptance-template.md) фиксирует границы
приёмки и согласование владельца; тесты его не подписывают.
