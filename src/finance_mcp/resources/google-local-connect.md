# Локальное подключение Google Sheets — TASK-574, промежуточный этап

Реализовано в ветке task574-local поверх 0.6.0. Это ещё не принятый внешний релиз.
Реальный Google/UI тест нового сценария не выполнен.

## Запуск агентом на компьютере владельца

После установки extra sheets в отдельную venv:

    python -m finance_mcp.google_connect --profile owner

Можно передать согласованную ссылку через --url. --app указывает на настройки
зарегистрированного Desktop OAuth приложения автора; клиент не создаёт Cloud project.
При готовом комплекте настройки приложения находятся в resources/google-oauth-client.json.
В исходном репозитории такого файла пока нет; готовый комплект ещё предстоит собрать.

Команда открывает существующий OAuth login, когда разрешение профиля не сохранено,
читает только книгу по ссылке, предлагает лист/вид отчёта, спрашивает месяц, валюту
и подтверждение готовности к анализу. Пользователь не составляет JSON-карту.
Пароли, коды и токены не вводятся в чат. Google Testing пока требует Test user.

По умолчанию профиль сохраняется в ~/.finagent/profiles/<profile>. Генерируются
config.json, паспорт, метаданные периодов/отчётов/примечаний и mcp.json с фактическим
Python и абсолютным путём конфигурации. Исходные суммы в локальные CSV не копируются.
Перезапуск команды использует сохранённый профиль; другая книга требует нового имени.
Профиль не перезаписывается автоматически.

## Поддержанная структура первого этапа

Один выбранный лист/вид отчёта и один подтверждённый месяц.
В колонке A — уникальные названия строк. Месяцы с годом — в одной строке
в первых 30 строках листа: YYYY-MM, YYYY-MM-01, MM.YYYY, 01.MM.YYYY,
«октябрь 2026», «October 2026». Числовая дата Google допускается только
с явным заголовком колонки A «Статья»/«Показатель»/Article/Metric.
Суммы — числовые ячейки Google, без текстового форматирования валют.
Итоги и детали возвращаются отдельно, без общего сложения и смены знаков.
Пустая сумма — missing, числовой ноль — value/0. complete=false, as_of unknown.

Лимиты: до 30 листов, до 100 колонок, до 5000 строк на лист; нужна свободная
последняя строка диапазона. Другие листы перечисляются как неподключённые.
Несколько таблиц на листе, повторные месяцы/названия, план/факт рядом,
дополнительные колонки и журнал операций автоматически не подключаются.
Это явные границы первого этапа, не универсальное распознавание любых книг.

## Первый результат и подключение приложения

Возвращаются source_connected, first_analysis со ВСЕМИ исходными строками
и ограничениями, пути config/mcp.json, ui_connected=false.
Первый разбор не вычисляет прибыль из ДДС и не складывает итоги с деталями.
MCP затем запускается штатно с --config <сохранённый config.json>.
Изменение/вставка/перестановка строк или заголовка выбранного месяца требует
повторной проверки карты; неудачное обновление блокирует новый финансовый ответ.

mcp.json — подготовленные настройки. Автоматическая регистрация в выбранном
клиенте, упаковка приложения, реальное stdio нового Google-профиля и проверка
в интерфейсе — следующие этапы. Готовность файлов не означает UI-подключение.

## Проверки

12 новых тестов: настоящий discovery → сохранение файлов → load_adapter →
GoogleSheetsAdapter → FinanceService → MCPServer.call_tool; подменён HTTP-транспорт.
Все 5 строк эталона сверены по имени, сумме и статусу, в том числе итог/детали,
пропуск/ноль. Контроли ошибок URL/Google/формата/подтверждения/повтора/изменения карты.
Полный suite: 72 теста, 65 passed, 7 PostgreSQL skipped. Настоящий Google и
новый внешний пользователь этими тестами не подтверждены.
