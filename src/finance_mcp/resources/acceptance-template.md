# Акт сверки и подключения финансового MCP

**Статус: НЕ ПРИНЯТО — шаблон не заполнен.**

Зелёные preflight, --check и тесты подтверждают только свой объём. Они не заполняют
этот акт, не согласуют методику и не подтверждают правильность финансов автоматически.
Оригиналы и подробная сверка хранятся у клиента; секреты/DSN/персональные данные сюда не входят.

## Источники и даты

| Отчёт/период | Независимый исходный отчёт / отпечаток | as_of и подтверждённый TZ | received_at | as_of_status / ограничения |
|---|---|---|---|---|
| … | … | … | … | … |

`as_of` — дата состояния источника. При неизвестной дате/TZ: as_of=null,
as_of_status=unknown, исходный текст в source_time_raw, aware received_at отдельно.
Время получения не доказывает свежесть учёта. Неизвестность не снимается подписью --check.

|---|---:|---:|---:|---:|---:|---:|---|
| … | … | … | … | … | … | … | … |

- Эталон подготовлен независимо от адаптера / преобразователя (как именно): …
- Статьи, разрезы, коды, статусы и метаданные: число сравнённых ячеек / результат: …
- Файл подробной сверки с каждой ошибкой и её причиной, SHA256: …
- Денежные тождества / межмесячная непрерывность: проверено N, результат: …
- Объяснённые методические различия (строки, суммы, решение владельца): …

Совпадения итогов недостаточно. Пустые выборки и неполные источники не дают приёмку
несуществующих данных. Исправленный источник или алгоритм требуют свежего прогона сверки.
