# Сообщения об уязвимостях

Не публикуйте секреты и детали доступа к данным в открытых Issues.
Для первичного контакта используйте https://finuchetai.ru/ и укажите тему
«Уязвимость финансового MCP», версию пакета и краткий класс проблемы без ключей
и клиентских данных. Способ передачи подробностей согласуется отдельно.

Проект находится на стадии первого публичного выпуска. Гарантированные сроки
исправлений и расширенная поддержка версий пока не заявлены.
Реальные роли БД должны иметь только согласованные права SELECT;
аннотация MCP readOnlyHint не заменяет ограничения источника.
