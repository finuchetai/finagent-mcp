# Участие в проекте

Сначала прочитайте README.md и AGENTS.md. Установка — в отдельную venv.
Перед изменениями выполните preflight и короткую stdio-пробу, после — затронутые
проверки и `python -m unittest discover -s tests -v`. PostgreSQL-проверки требуют
отдельного временного runtime; пропуск не считается проверкой PG-адаптера.

В pull request опишите проблему, изменение и выполненные проверки. Изменения
финансовой методики должны иметь явное описание и независимые ожидаемые значения.
Используйте только искусственные примеры. Не добавляйте ключи, DSN, выгрузки
реальных клиентов или команды записи в их источники.

Изменения предлагаются под лицензией MIT проекта. Авторство сторонних фрагментов
и условия их лицензий сохраняются. Вопросы о сервисе: https://finuchetai.ru/.
